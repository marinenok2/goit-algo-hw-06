# Адресна книга на Python

Навчальний проєкт з об’єктно-орієнтованого програмування. У файлі `main.py` реалізовано адресну книгу для зберігання контактів і роботи з їхніми телефонними номерами.

## Можливості

- Додавання, пошук і видалення контактів за ім’ям.
- Зберігання кількох телефонів для одного контакту.
- Додавання, пошук, редагування та видалення телефонів.
- Перевірка імені: воно не може бути порожнім або складатися лише з пробілів.
- Перевірка телефону: номер має містити рівно 10 цифр.

## Структура

Усі класи розміщені у `main.py`:

| Клас | Призначення |
| --- | --- |
| `Field` | Базове поле для зберігання значення. |
| `Name` | Ім’я контакту з перевіркою. |
| `Phone` | Телефонний номер з перевіркою. |
| `Record` | Контакт з ім’ям і списком телефонів. |
| `AddressBook` | Колекція контактів на основі `UserDict`. |

## Запуск

Потрібен Python 3. Додаткові бібліотеки встановлювати не потрібно: використовується лише стандартна бібліотека.

```bash
python main.py
```

Програма виконає демонстраційний приклад: створить контакти John і Jane, змінить номер, знайде та видалить телефон, видалить контакт і покаже обробку неправильного номера.

## Приклад використання

```python
from main import AddressBook, Record

book = AddressBook()

record = Record("Олена")
record.add_phone("0501234567")
book.add_record(record)

contact = book.find("Олена")
if contact is not None:
    contact.edit_phone("0501234567", "0671234567")
    print(contact)

book.delete("Олена")
```

Методи `find()` і `find_phone()` повертають `None`, якщо запис не знайдено. Неправильне ім’я чи телефон, а також спроба редагувати відсутній номер спричиняють `ValueError`. Якщо новий номер некоректний, попередній номер залишається без змін.

Дані зберігаються в пам’яті під час роботи програми. Збереження у файл та інтерактивний інтерфейс не реалізовані.

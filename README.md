# Адресна книга на Python

Навчальний проєкт з ООП для роботи з контактами.

## Можливості

- Додавання, пошук і видалення контактів.
- Додавання, пошук, редагування та видалення телефонів.
- Перевірка імені та номера телефону (рівно 10 цифр).

## Запуск

Потрібен Python 3, без додаткових бібліотек.

```bash
python main.py
```

Файл `main.py` містить класи адресної книги та демонстраційний приклад. Дані зберігаються лише в пам’яті.
